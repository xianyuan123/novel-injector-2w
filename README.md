# Novel Injector（小说注入器）

SillyTavern（酒馆）第三方扩展。先把小说清洗成压缩正文、剧情节点和角色资料，再在聊天时注入相关内容；支持向量检索、穿书进度、用户代入、世界设定与文风。

> **已经支持自定义上下文注入位置。** 打开插件 → **处理** → 向下找到并展开 **注入设置** → 展开要调整的分类，即可设置 **注入位置、注入深度、消息角色**。各类内容可以分别设置，详见下文。

## 安装与上手

在酒馆的扩展安装入口粘贴：

```text
https://github.com/xianyuan123/novel-injector-2w
```

安装后刷新页面，点击顶部的书本图标打开插件。手动安装则把仓库放到 `SillyTavern/public/scripts/extensions/third-party/novel-injector`，目录内须包含 `manifest.json`、`index.js`、`lib/` 等文件。

1. **处理** → 上传 `.txt` 或 `.mobi` 小说。
2. 点清洗区域的设置齿轮，填写 **清洗 API 地址、Key、模型**。需要兼容 OpenAI Chat Completions 的接口；插件不提供模型。
3. 点 **开始全自动清洗**，等待处理。清洗会产生压缩正文、剧情节点和角色资料，支持暂停与续跑。
4. **阶段** → 开启想让 AI 参考的阶段，再回到聊天窗口发消息。需要调整阶段划分时，到 **剧情** 页操作。

**不做向量化也能使用。** 想按语义检索片段，再到处理页配置兼容 OpenAI Embeddings 的向量接口，选择阶段并向量化。聊天模型与向量模型用途不同，不能混填。

| 页面 | 常用操作 |
|---|---|
| 处理 | 上传、清洗、API 配置、文风生成、向量化、注入设置 |
| 剧情 | 剧情节点编辑、阶段划分、世界设定、偏差分析、穿书模式 |
| 角色 | 角色资料、注入开关、AI 更新人设、用户代入 |
| 阶段 | 阶段开关、标题与概括、角色演绎提示词、未向量注入方式 |
| 设置 | 插件总开关、全局提示词、自动保存、主题、小说库、导入导出 |

### 连载还没完结？前面的先洗，后面的用「追加章节」接上去

上传区下面有个 **追加章节** 按钮，专门给「一本小说分好几次拿」的情况用：

- 它只把新文件的正文接到当前小说**末尾**，按同样的分段大小生成**新分段**；已有分段的序号、清洗结果、剧情、角色、阶段划分和向量**全部不动**。
- 接完在分段列表里能直接看到多出来的段落，点 **开始清洗** 只会跑那些还没处理的分段（未完成的补上，已完成的跳过）。
- 接完建议到 **剧情** 页重新划分一次阶段，让新内容落进阶段里；老阶段的概括不受影响。
- 同一份文件不会被追加第二次（会直接提示「已经追加过了」）；接错了想退回，用 **设置 → 小说库** 里追加之前的快照。

### 换了向量模型？点一下「重建索引」

向量是用某个模型算出来的，换模型（或换端点）之后，旧向量的维度/空间都对不上新模型，硬用效果会很差。处理页顶部那行状态会变黄提示「向量的来源与当前设置不一致」，旁边出现 **重建索引** 按钮：

- 点它 → 确认 → **只清掉向量**（剧情、角色、清洗结果、阶段划分都不动）→ 立刻用当前设置重新向量化，不用再去设置页点「清除向量缓存」再跑回来点「开始向量化」。
- 它只在「确实有已存向量」且「当前不在向量化中」时出现，平时不占地方。
- 重建要重新消耗一次 Embedding 费用，脚本长了会比较久；中途可以点旁边的 **停止**。

## 注入位置与内容

**入口：处理 → 注入设置。** 先展开“注入设置”，再展开其中的“角色人设”“阶段剧情（未向量）”“向量块”等分类。阶段页那一整块注入开关收在顶部的「注入策略」横条里，折叠状态也会记住。

- **注入位置**：`主提示前`、`主提示后`、`聊天内` 三选一。
- **注入深度**：选择“聊天内”时，`0` 表示对话末尾；数字越大，插入位置越靠前。它不是阶段编号，也不是召回数量。
- **消息角色**：`系统`、`用户`、`助手` 三选一，决定这段资料以哪种消息身份发给模型。

**向量块能注入多少？** 展开 **向量块** 后有两个数量控件：

- **单轮最多 Token**：单轮向量片段的总体积上限，默认 `20000`（≈30000 字），范围 256～200000。当前阶段片段优先占用预算，剩下的留给原著前情；装不下的低分片段直接丢掉，不会把正文撑爆。
- **最多召回片段数**：单轮最多取几个片段，默认 `30`（上限 60）。
- **保底召回片段数**：相似度阈值是**及格线**，不是名额。默认 `0`（关闭）时只取及格的片段——及格几个就注入几个，所以你可能会发现「明明把召回数调到 40，却只进来 3～4 块」。把它设成 `40` 就会补齐到 40 块：及格的片段优先，不够再按相似度从高到低把不及格的补进来。范围 0～200。
- **前情最多召回片段数**：原著前情（更早阶段）单独的名额，默认 `2`，范围 0～50。设为 `0` 则不注入前情。
- **向量块切分（字）**：向量化时每个索引块的字符数，默认 `1000`（≈667 Token），范围 200～4000。**改动后需要重新向量化**才会按新粒度建索引，旧块仍按原粒度检索。

> **实际取块数 = max(最多召回片段数, 保底召回片段数)**，再按 Token 预算逐块裁剪。
>
> 一个片段的实际体积 ≈ `向量块切分` × 1.5 Token。默认 1000 字时，单轮 20000 Token 最多只装得下约 30 块——想要 40 块就必须把预算提到 30000 以上（40 × 667 ≈ 26680 Token）。
>
> 常见坑：**预算才是真正的天花板**。哪怕保底设成 200，装不下的块照样在裁剪阶段被丢掉，最后进正文的仍然只有预算允许的那些。

| 分类 | 发给 AI 的内容 | 默认位置 / 深度 |
|---|---|---|
| 全局提示词 | 内置头部、尾部规则 | 头部：主提示前 / 0；尾部：聊天内 / 0 |
| 角色人设 | 已开启的角色资料 | 主提示前 / 4 |
| 阶段剧情（未向量） | 剧情节点或压缩原文 | 聊天内 / 4 |
| 偏差注入 | 已分析出的剧情偏差与分支事实 | 主提示前 / 0 |
| 向量块 | 根据对话检索到的相关片段 | 聊天内 / 4 |
| 世界设定 | 已开启且有内容的世界设定分类 | 主提示前 / 4 |
| 文风 | 已生成的文风执行指南 | 主提示前 / 4 |

以上默认消息角色均为“系统”。全局提示词的来源在 **设置** 页选择：不使用、跟随酒馆预设、使用插件内置。跟随酒馆预设时，可指定插件使用的已保存预设，不影响前台 RP 的预设选择。位置设置只决定资料放在哪里，**不会自动生成资料或打开对应模块**。

### 阶段与向量有什么区别？

**阶段就是一组剧情的开关单位**，例如一卷或一个篇章。普通模式下：

| 阶段状态 | 如何注入 |
|---|---|
| 已开启、已向量化 | 根据当前对话检索相关片段 |
| 已开启、未向量化 | 直接注入该阶段的剧情节点或压缩原文 |
| 已关闭 | 不参与普通模式的阶段注入 |

直接注入的内容在 **阶段 → 未向量注入** 中选择：“剧情节点”更省 Token，“压缩原文”细节更多。

普通模式的直接注入默认上限为 **32000 Token**，可在 **处理 → 注入设置 → 阶段剧情（未向量）** 调整。超出时优先保留当前阶段，再尝试阶段概括，仍放不下的阶段会省略。页面会显示本轮估算用量与省略情况。

**想让 AI 严格按本阶段剧情走？** 打开 **处理 → 注入设置 → 阶段剧情（未向量）** 里的 **当前阶段全量直注**（默认关闭）。开着向量化的玩法也能用：

- **当前阶段**整段剧情（跟随「未向量注入」模式，选节点或压缩原文）直接注入，发的是**这个阶段的全部剧情**，不是当前一个节点；不召回、也不受「单轮最多 Token」裁剪，上限单独放宽到 **200000 Token**；内容真的极长时才会截断。
- **更早的阶段仍然按向量召回**——当前阶段跟剧情，前情靠检索，两者不打架。
- 被整段直注的当前阶段会从召回池里移除，同一段剧情不会注入两次。
- **穿书模式下**：整阶段直注会接管剧情注入，穿书自己那套「当前节点」持续提示词随之暂停，避免同一段节点正文进两次；「开场 / 推进」这类一次性提示词不受影响。
- 开关开着但当前阶段没启用时不生效，面板会提示；没有向量数据时按钮自动隐藏（那种情况本来就会整段直注）。
- 关掉开关，行为与以前完全一致。

**角色、世界设定、文风等有各自的开关或内容条件，不由阶段开关统一控制。** 想停用全部注入，到设置页关闭插件总开关。

### 怕 AI 把剧情走偏？把本阶段剩下的剧情和后面几阶段提前给它看

**入口：处理 → 阶段** 的「**未来剧情预告**」（默认关闭），紧挨着「当前阶段全量直注」。

玩到第 8 阶段第 2 个节点时，当前阶段后面的节点**不该发**——发了就等于剧透，AI 会提前把剧情跳过去。但完全不告诉它「后面大概会发生什么」，它又容易把人物关系、伏笔、关键事件写歪。这个开关就是补这个缺口：

- **当前阶段也算（默认勾选）**：把当前阶段**还没演到**的节点**全部**放进预告——这正是没开「全量直注」时最容易写偏的地方。穿书模式下从「正在进行的那个节点」的**下一个**开始取，已经演过的不会重复发；普通模式没有逐节点进度，就从该阶段第一个节点开始取。
- **往后 N 个阶段**：从当前阶段的**下一个阶段**开始，按顺序取 N 个阶段（默认 1，可填 0～20）。填 0 且勾着「当前阶段也算」= 只预告当前阶段剩下的剧情；填 0 且不勾 = 完全不注入。
- **往后每阶段 M 个节点**：只约束**后面的阶段**——每个后面的阶段按剧情顺序取前 M 个节点（默认 2，可填 0～20；**填 0 表示这个阶段的全部节点**）。**当前阶段不受这个数字限制**：本阶段还没演到的节点**全部优先**放进预告，剩下的有 8 个就发 8 个，不会发 4 个就跳到下一阶段。总量仍受下面的 Token 上限约束，装不下时同样是先保住当前阶段、后面的阶段从边界处停住。
- 注入的内容带一句明确声明：「以下内容尚未演到，只用来把握整体走向、提前埋设伏笔，不要跳过当前剧情直接写，也不要让角色说出此刻还不该知道的细节」。
- 和「未向量注入」共用同一个模式与 Token 上限：选「剧情节点」就发明细节点，选「压缩原文」就发这些阶段涉及的清洗分段（每段截断到 1500 字）。总长超过上限时在**节点边界**处停住，不会把半句话切给模型。
- **不会重复注入**：当前阶段如果已经整段发过了（开了「全量直注」，或它是未向量阶段、走了整阶段注入），预告就自动跳过当前阶段，只发后面的阶段——同一段剧情不会在一轮里出现两次。
- **跳过被关闭、被整段屏蔽的阶段**，也**跳过被屏蔽的节点**——屏蔽规则优先级更高，不会出现「明明屏蔽了却又从预告里冒出来」。
- 面板下方的说明会实时告诉你本轮会注入哪几个阶段；当前是最后一个阶段、或后面没有可用阶段时会提示。
- 「当前阶段」的口径与全量直注完全一致：穿书模式取当前进行节点所在阶段，普通模式取**最后一个开启的阶段**，或者用下面的「进度锚点」手动指定。所以普通模式下想让它从第 8 阶段往后看，可以填个锚点，也可以把 9 之后的阶段先关掉。
- 关掉开关，行为与以前完全一致。

### 主视角之外也在发生事？开「后台动向」，让世界不静止

**入口：处理 → 阶段** 顶部「注入策略」横条右侧的「**后台**」按钮（默认关闭）；穿书模式下也可以直接在聊天结尾阶段状态栏的「**后台动向**」里查看和当场推演。

你演的是主角，但师父在山门、掌柜在城里、对手在别处，他们也该有自己的动作。完全不管，世界就是静止的布景；全都让 AI 自由发挥，又容易前后矛盾。这个功能在节点推进时补一轮「别处发生了什么」：

- **推演节奏**三选一：
  - **节点有动向才推演**（默认）：只有当前节点真的换了一个才推一次，同一节点不重复请求。
  - **每回合都推演**：每条 AI 回复后都推一次，适合节奏快、多线并进的剧情。
  - **只手动推演**：平时完全不发请求，想用时打开弹窗点「推演一轮」。
- **用哪个模型**：当前对话模型 / 插件里配置的 API / 外接 OpenAI 兼容接口。外接接口自己填地址、模型名、Key、超时；地址只填到域名或 `/v1` 会自动补 `/chat/completions`，填了地址就优先走它。
- **主视角**：留空就用当前角色卡的名字（`name2`/`name`）。推演只写主视角看不到的人或势力，当前在场的人物会被要求排除。
- **覆盖后续阶段**：可让推演顺带考虑「未来剧情预告」覆盖的那几个阶段的后续节点（0 = 只看当前阶段）。
- **注入上限**：默认 800 字，超出后在**条目边界**停住并注明「另有 N 条未注入」，不会切半句话。注入位置、深度、角色跟随「剧情 / 未来预告」那组设置。
- **记录可管**：弹窗里按时间倒序列出所有动向，可单条删除、一键清空；最多保留 24 条，同一主体新动向覆盖旧的并保留首次出现时间。记录跟着聊天保存，切对话各自独立。
- **穿书时就在状态栏里**：聊天结尾那条阶段状态栏底部多了一栏「**后台动向**」，默认收起；展开能直接看动向（主体 / 阶段 / 一句摘要），点「×」删单条，点右上「推演」当场跑一轮。它和弹窗是同一份数据，任一边改动另一边立刻同步。
- **失败不打扰**：请求报错、超时、回复解析不出来，都只写控制台，不弹错、不影响正文；只有手动点「推演一轮」时才提示原因。
- 关掉开关 = 完全回到以前的行为，不产生任何额外请求。

### 删错了、没反应、第一次用？三个小东西兜住

都不影响正文生成：出问题也只会少一个提示，不会让这一轮发不出去。

**1）删错了能撤回。** 删剧情事件、清空后台动向、清空变更记录之后，屏幕下方会浮出一条「已删除 N 个剧情事件 · **撤销** · 30s」。30 秒内点一次就整批恢复，超时自动消失。撤销只把数据放回去并重画界面，不会再调一次接口。

**2）出问题有个红点。** 处理页右下角的小圆点，平时不出现；一旦有失败就亮起来并显示条数。点开是一张清单，按时间倒序写着「哪个功能、什么错、什么时候、重复了几次」：

| 会进清单的记录 | 说明 |
|---|---|
| 向量召回失败 | 接口报错、超时、读不到索引，这一轮就是没有召回 |
| 后台推演失败 | 其他视角那轮请求失败，正文照常生成 |
| 后台动向注入失败 | 拼注入文本时出错，跳过这一块 |
| 自动推进判定失败 | 判定请求没发出去或没回来，这一轮不推进 |
| 自动推进（没前进） | 判定跑通了，但结论是「还没演完」或解析不出来；会连原因一起记，**不等于报错** |
| 上下文注入失败 | 整条注入链抛出没人接的异常时，兜底记一条 |

同一条记录 30 秒内重复出现只累加 `×N`，最多留 50 条，可一键清空。

注意范围：**剧情节点、未来预告这类局部注入的小失败通常只写浏览器控制台**，不打断本轮生成；**保存失败也不进清单**。所以红点没亮不代表一定没出过问题——排查「这轮怎么没内容」时先看这里，再去控制台补刀。

**3）第一次用有个清单。** 第一次打开插件、且还有没做的步骤时，处理页顶部会出现四步卡片：

**导入章节 → 清洗正文 → 拆分阶段 → 写入向量**

做完的步骤打勾并置灰，当前该做的那步高亮。点一下会切到对应的工作页——但第 3、4 步只是把你带到**阶段页**：**划分阶段**的按钮在剧情页顶部，**开始向量化**的按钮在处理页的向量卡里，到了阶段页还得自己切过去。四步都完成后自动消失；不想看可以点「不再提示」（记在本机，换设备会重新出现）。

### 想看整个故事怎么铺开的？切到「时间线」

**入口：处理 → 阶段** 顶部「列表 / 时间线」切换里的**时间线**。

- 阶段从左到右排开，一列一个阶段；每列内部按 **主线 / 支线 / 转折** 三条泳道摆节点，哪条线在哪一段推进、哪一段是空的，一眼看完。
- 列头写着这一阶段有几个节点、多少字、大概多少 Token，以及**已向量 / 未向量**；**当前进度**所在阶段用主色描边并挂「现在」；关掉的阶段整列变淡；**召回屏蔽**的阶段整列斜纹、标题加删除线；被屏蔽的节点是虚线卡片。
- 它是**只读**的：点阶段头或任意节点，会切回列表并滚动定位到那个阶段，方便你接着编辑；不会改任何数据，也不影响注入。
- 阶段多的时候横向滚动即可，视图选择会记住，下次进来还是时间线。

### 只想开其中几个阶段，还要一个个点？用「批量勾选」

阶段页的「全部开启 / 全部关闭」旁边有个 **批量勾选**：点一下把所有阶段列成一页清单，勾完点「应用勾选」一次性生效。

- **每页 20 或 30 个**，阶段多的时候翻页勾，不用跟着卡片一页页翻。
- 支持 **本页全选 / 本页清空**，顶部实时显示「已选 21 / 30（本页 20/20）」，勾到哪一步心里有数。
- 打开时默认勾上「当前已启用」的阶段，所以它也能当「关掉几个」用：取消勾选再应用就是关闭。

> 它改的就是每个阶段卡片右上角那个开关，两者随时可以混用。
### 角色页要翻好几页？直接搜，别翻

角色页顶部有一条搜索框，**名字、身份、外貌、性格、关系都能搜**，空格分词——`青云 沉稳` 这种组合也能用。命中的名字会在卡片上标出来。

| 想干什么 | 怎么做 |
| --- | --- |
| 找某个角色但忘了在哪个分类 | 点「全部」，五个分类都带人数徽标 |
| 只找反派里的某个人 | 先点「反派」，再搜 |
| 按出场顺序看 | 排序选「按登场阶段」（默认） |
| 看谁的人设最厚 | 排序选「按人设长度」，卡片上有「N 字」 |
| 一次开关搜出来的一批 | 「全部开启 / 全部关闭」作用于当前筛选结果 |

搜完按 `Esc` 或者点输入框右边的 ×，就回到完整列表。
### 原著里死了的人还在说话？给角色填「退场、关系变化、知情」

角色卡点「编辑」之后，除了身份外貌性格，多出三样东西：

| 填什么 | 解决什么 |
| --- | --- |
| **退出阶段 + 方式** | 原著第 7 阶段死掉的角色，从第 7 阶段起不再注入人设，模型不会让他继续出场 |
| **按阶段关系** | 关系按阶段切换：「第 1–4 阶段：同门师姐」「第 5 阶段起：反目成仇」，注入时只发当前阶段成立的那条 |
| **知情** | 这个角色「从第几阶段开始知道什么」，注入时只发他已经该知道的部分，防止配角提前说出只有主角知道的事 |

另外卡片上有「**出场索引**」：点一下会扫全部节点正文，告诉你这个角色在哪几个节点出现过、各几处、原句长什么样。名字写法跟正文对不上时，这里一眼就能看出来。

这些设定都按「当前阶段」生效。当前阶段取的是本轮注入实际用的那个阶段（有「进度锚点」就是锚点阶段）。

**同一个人有好几个叫法，模型当成两个人？填「别名」。**
原著里角色常有本名、道号、绰号、尊称（血刀老祖 / 老祖 / 老魔）。只认一个名字会出现三种问题：正文写「老祖」时自动休眠以为这人没出场、搜索搜不到、模型把「老祖」当成新角色另开一条线。编辑区「别名」一行用顿号分开填上即可，之后人设注入、搜索、出场索引、在场判定都会一起认。

**同一个人的两层身份，又不想提前剧透？用「多身份」。**
「夏弥 / 黑影」这种不是别名：揭晓之前，模型应该把黑影当成一个来历不明的东西，而不是「夏弥变的」。在编辑区「多身份」里加两行——`夏弥（从 1 到 5）`、`黑影（从 1 到 9，勾「秘密」，揭晓 = 6）`——之后：第 1–5 阶段注入的是「身份：夏弥」加「另一形态：黑影（来历不明，真实身份尚未揭晓）」；第 6 阶段起自动变成「身份关系：黑影 与 夏弥 是同一人」。在场判定和出场索引也会把两个名字算作同一个人。

### 阶段页挤成一团？收起来，还能先看一眼这轮到底发什么

展开后是 **六张分组卡**：阶段启用 / 注入范围 / 提前预告 / 召回屏蔽 / 预算沙盘 / 进度锚点，一组只管一件事，不会所有开关挤在一起。


**入口：处理 → 阶段** 顶部那条「**注入策略**」横条。未向量注入模式、当前阶段全量直注、全部开启/关闭、未来剧情预告、召回屏蔽都收在这条横条里，默认**折叠**。

- 折叠时横条只留一行摘要，把这轮的注入策略写清楚：召回第几阶段、直注第几阶段、预告从第几阶段到第几阶段、屏蔽了几项。不展开也知道这轮会发什么。
- 展开后**一个功能一张卡**（阶段启用 / 注入范围 / 提前预告 / 召回屏蔽 / 预算沙盘 / 进度锚点），每张卡都是「标题 + 一行说明 + 这一组的控件」；开关做成整条可点的拨动开关，数字框只占自己该占的宽度，按钮都有边有底。面板窄（酒馆侧边栏常见的 320～420px）时卡片自动排成单列，宽屏才并成两列，所以不管侧边栏多窄都不会把两个功能挤在一行。
- 点横条展开/收起；键盘聚焦后按**回车或空格**同样可以切换。展开状态会被记住（`stageInjExpanded`）。
- 横条右侧的 **预览** 按钮打开「**本轮注入预览**」：

| 预览分区 | 内容 |
|---|---|
| 向量召回 | 本轮召回的片段（点「预览召回」才会真的去检索，会调用一次向量 API） |
| 当前阶段直注 | 开了全量直注时整段发出去的内容 |
| 未来剧情预告 | 勾了预告时会发出去的后续剧情 |
| 后台动向（其他视角） | 开了后台推演时，别处正在发生什么 |
| 角色人设 / 世界设定 / 文风 / 偏差 / 全局提示词 | 这些设置项各自会注入的正文 |

每段都标了**字符数、Token 估算和占比**，顶部给总账（总字符数、总 Token）。预览用的是**和实际注入同一套构造函数**，所以看到的就是会发出去的，不会「预览一套、实际一套」。除了「预览召回」那一块，其余都是本地计算，不发请求。

### 这轮到底为什么发这段？看「注入溯源」

预览弹窗里，向量召回那个分区下面会多一张**溯源表**：召回的每一块都标着**它在哪一阶段、打了多少分、命中了哪些关键词、最后是「已注入」还是「超预算丢弃」**。表头还有一行总账（阈值、候选数、过线数、注入数、因预算丢掉几个、屏蔽了多少阶段与块、这次的字数预算）。

**入口**：注入策略 → 横条右侧 **预览** → 滚到「向量召回」下面。

- 只有分数，不写理由的那种「黑箱召回」在这里就透明了：能看出是关键词命中的，还是纯语义相似捞上来的。
- `超预算丢弃` 说明它不是没被检索到，而是排序靠后、预算用完被挤掉了——这时候该调的是注入上限，不是召回阈值。
- 溯源信息只记录、不参与排序，所以看与不看，注入结果完全一样。

### 数据脏了？跑一次「数据体检」

设置页有一张**数据体检**卡，点一下「开始体检」，只翻本地数据、不花 API，几十毫秒出结果。查七类东西：

| 检查 | 查什么 | 为什么会坏 |
|---|---|---|
| 重名角色 | 同名、或名字互相包含的两个角色 | 注入时重复占位，AI 当成两个人 |
| 孤儿剧情节点 | 没阶段号，或阶段号超过了总阶段数 | 阶段直注与未来预告永远取不到它 |
| 缺向量的阶段 | 有节点但没算向量的阶段 | 语义召回会漏掉这些剧情 |
| 没清完的分段 | 还是 pending / 上一次失败的段 | 剧情与角色会缺一块 |
| 正文零命中的角色 | 名字在整个正文里一次都没出现 | 多半是清洗时模型编出来的 |
| 退场后又出现 | 标了退场阶段，后面的节点里又冒出来 | AI 会把它写活，「诈尸」 |
| 还没划分阶段 | 有节点但阶段数是 0 | 没有阶段就没有直注与预告 |

每条都写了**「怎么修」**：该去角色页合并、该点「补全缺失」、还是该重新划分阶段。体检只读，不会动你的数据。

### 谁在第几阶段知道什么？打开「知情矩阵」

角色页工具栏上有个 **知情矩阵** 按钮，点开是按角色排的卡片，每张卡里只列**身份或已知事实发生变化**的那几个阶段：

- 身份层按 `fromStage` 生效，秘密身份在 `revealAt` 之前标成「秘密：…」——这一栏的东西 AI 在那一阶段不该说破。
- 「知道：…」列出该阶段已经知道的事（按 `fromStage` 累积）。
- 当前阶段那一行会描一道主题色边框，标「当前」，方便确认这轮发出去的身份对不对得上。

这是排查「AI 提前泄底」最快的办法：一眼看出某个身份是在第几阶段才揭晓，而你把进度锚点设在了第几阶段。

### 预算砍到多少会掉东西？拖一下「预算沙盘」

注入策略面板里新增**预算沙盘**卡：拖滑条试一个 token 上限，下面实时列出**这个预算下每个阶段发多少 token**，以及 `先掉的阶段：第 X、Y 阶段`；预算够用时会直接写「这个预算下都能装下」。

**入口**：处理 → 阶段 → 注入策略 → 预算沙盘。

- 全部本地计算，**不发请求、不改你的设置**：用的是当前配置的副本，只是把 `plotInjMaxTokens` 换成滑条上的值。
- 调参顺序因此变得很直观：先把预算拖到「刚好开始掉阶段」，再把那个值填进注入上限，既不浪费上下文，也不至于悄悄漏掉一个阶段。

### 知道自己在第几阶段，但插件猜错了？用「进度锚点」

**入口：处理 → 阶段** → 展开「注入策略」→ 最后一张卡「**进度锚点**」。

普通模式下插件只能按「最后一个开启的阶段」猜你在哪。如果你开了好几个阶段、实际只演到第 8 阶段，猜出来的位置就可能偏。手动填一下：

- **第 N 阶段**：填了之后，**全量直注取这一阶段**、**未来预告从这一阶段的节点之后开始**。填 `0`（默认）＝按原来的自动口径判断。
- **阶段里的节点**：下拉里按剧情顺序列出该阶段的全部节点，选中的那个会被当作「已经演过」，预告从它**后面**开始。不选就是「从阶段开头」。
- **自动**：清掉锚点，回到自动判断。
- 换阶段会自动清掉节点选择，不会拿上一阶段的节点当锚点；阶段号填越界（比如只有 10 个阶段却填 12）会自动退回自动判断，换小说、重新划分阶段之后也不会锚到一个不存在的阶段。
- **穿书模式本来就有当前节点**，锚点不生效，展开后会直接写明原因。
- 锚点只决定「取哪一阶段」和「预告从哪开始」，**不改全量直注的开关**：那个阶段关着，仍然不会直注。

### 想让某段剧情不要再出现？用「召回屏蔽」

**入口：处理 → 阶段** 每张阶段卡下方的「召回屏蔽」一行。当某个阶段里有一段你不想再让它进上下文的剧情（比如穿越回来后的旧时间线、已经作废的支线），可以直接屏蔽掉。

- **一键屏蔽本阶段**：整个阶段的剧情都不再被召回、也不再被阶段直注。阶段卡会显示「整段已屏蔽」。
- **多选节点**：点开后阶段里的主线 / 支线 / 关键转折会列出勾选框，逐个勾掉不要的节点，再点 **屏蔽勾选**。也可以直接点整行来勾选。
- **一键解除屏蔽**：把该阶段的整段屏蔽与逐个节点屏蔽一起清掉。
- 徽标会实时显示「已屏蔽 3/12」这类进度；被屏蔽的节点在列表里带「已屏蔽」标记。
- **屏蔽按节点本身记住**，不按下标——重新解析、重新划分阶段之后依然有效，刷新页面、重开聊天都在。
- 屏蔽同时管住两条路：向量召回不选它，**阶段直注（含「当前阶段全量直注」与穿书模式的节点注入）也不会发它**。
- 只有当一个原文分段里的节点**全部**被屏蔽（或所在阶段被整段屏蔽）时，这一整块才不召回；同块里还有没被屏蔽的剧情时，该块照常保留，不会误伤。
- **一个要知道的限制**：向量召回的最小单位是「按字数切开的原文片段」（默认 500 字），它和剧情节点不是一一对应的。所以当你只屏蔽了同一原文分段里的**个别节点**、而同块还有别的节点没屏蔽时，这个分段仍可能被召回，被屏蔽节点所在的那几百字也就可能跟着进来。想彻底不让它出现，用 **一键屏蔽本阶段**（整段屏蔽时该分段一定不会进），或者在清洗阶段把这段剧情单独分成一个分段。

#### 玩到第 8 阶段了，前面 1～7 阶段不想要？一键全屏蔽

**入口：处理 → 阶段的列表上方**，「召回屏蔽·全局」工具条。适合「已经推进到很后面的阶段，早期剧情全是已过期的前情」这种局面。

- **一键屏蔽之前阶段**：把**当前阶段之前**的阶段一次性整段屏蔽（例如当前是第 8 阶段 → 屏蔽第 1～7 阶段），**当前阶段与它之后的阶段完全不受影响**。再点一次同一个按钮就是**一键解除**（只解除「之前阶段」的整段屏蔽，不动你手动屏蔽的当前/之后阶段）。
- **当前阶段的判定与注入路径同一套口径**：穿书模式取「当前进行节点」所在阶段；普通模式取最后一个开启的阶段。所以你在第 8 阶段玩，它就会按第 8 阶段算。
- **多选阶段**：点开后每张阶段卡会出现一个勾选框，可**跨阶段勾选**（比如只想屏蔽第 2、5 阶段），勾完点 **屏蔽勾选的阶段（N）** 一次性屏蔽。再点一次「多选阶段」退出。
  - 这个按钮会**跟着勾选内容变意思**：勾的全是已经屏蔽的阶段时，它变成 **解除勾选的阶段屏蔽（N）**（文字会变红边），点一下就把这些阶段解封——所以在多选模式里屏蔽和解除是同一个按钮，不需要记两套操作；勾选里既有已屏蔽又有没屏蔽的阶段时，按「把没屏蔽的补上」处理。
- 工具条右侧会用一句话说明现在算的是第几阶段、之前一共几个阶段、已屏蔽了几个（例如「之前的阶段里已屏蔽 3/7（1、2、5）」）。
- 整段屏蔽某阶段时，顺手清掉该阶段里之前逐个勾选的节点屏蔽——免得以后解除整段屏蔽时冒出早就忘了的节点屏蔽项。
- 同样**不删任何数据**，解除屏蔽立刻恢复原样。

## 清洗与常用参数

清洗统一使用 **设置 → 全局提示词** 中的来源，不再单独选择清洗模式：

| 全局提示词来源 | 清洗请求组成 |
|---|---|
| 内置提示词 | 头部、尾部作为独立消息，按全局位置、深度和角色加入请求；清洗规则、前段参考、本段原文与执行指令分别保留 |
| 跟随酒馆预设 | 读取选定预设的已保存提示词，保留启用条目的角色、顺序和深度，把本次资料与执行指令放入 `chatHistory` 槽位 |
| 不使用 | 只发送清洗规则、资料边界、前段参考、本段原文与执行指令 |

清洗始终使用清洗面板配置的 API 和模型。“插件使用的预设”可选择具体名称，也可保留“跟随前台当前预设”。指定名称后，插件读取该预设的已保存提示词，前台可以使用另一个预设 RP；所选预设被删除时会提示重新选择。新增或更名后，可点击刷新按钮更新列表。

默认位置下，内置全局头部与清洗规则分别作为两条 `system` 消息发送，随后是小说资料和执行指令两条 `user` 消息；预览与实际请求使用同一份消息结构。

预设中的临时历史只用于本次清洗，不写入实际聊天，也不带入前台角色卡、世界书和聊天记录。小说原文不会经过宏展开或身份措辞替换；未启用 `chatHistory` 时，资料追加到预设末尾，预览中会说明。升级保留全局来源和已保存的自定义清洗提示词，移除旧版单独的清洗模式设置。

- **请求结构预览和失败响应记录 / 查看请求**：预览指定分段的消息角色、顺序、全局来源、预设名称和正文。预览不会调用模型；实际发送的请求及失败响应另有记录，仅在当前页面会话保留最近 10 次请求，响应最多展示 24000 字符，不展示接口凭据。
- **续跑清洗**：保留已完成分段，补齐失败和未完成的分段。
- **重新清洗**：先弹出确认框；确认后清空当前清洗结果、剧情、角色、阶段划分和向量索引，从头处理。只是补失败段时，请用“续跑清洗”。
- **生成此段**：只处理选中的一个分段。
- **自动续跑清洗**：默认关闭。开启后会反复补齐未完成分段，直到全部完成；每轮等待 3～30 秒，随时可暂停，全部完成后弹窗提醒。
- 自动清洗中，每段每轮**最多尝试 3 次**。失败提示会显示段号、具体原因和是否还会重试；主动暂停、跳过不会冒充接口故障。
- 同一段的重试复用首次组装的消息与模型配置。单段和自动清洗都优先使用紧邻前段已完成概括的末尾 800 字符作为参考；前段未完成时使用其原文末尾。

| 参数 | 默认值 / 说明 |
|---|---|
| 每段大小 | 100 KB；大段反复超时或截断时可调小，已完成分段会保留 |
| 清洗请求超时 | 15 分钟 |
| 清洗限速 / 并发 | 3 次/分钟 / 1 |
| 向量限速 / 并发 / 每批数量 | 3 次/分钟 / 1 / 16 |
| 基础向量召回 | 参考最近 3 条消息，相似度阈值 0.5，最多召回 30 段（上限 60）+ 前情 2 段（上限 50）；每块 1000 字，单轮总预算 20000 Token（≈30000 字）；保底召回默认关闭 |
| 自动推进（穿书） | 默认开启；每条 AI 回复后由模型判断「当前节点演完没有」，置信度达 0.7 才前进，可改成每 1–10 条判一次 |
| 自动跨阶段（穿书） | 默认开启；本阶段走完自动解锁并切到下一个还有未完成节点的阶段 |
| 自动保存 | 默认关闭，需要在设置页手动开启 |

### 流式输出：开和关，差在哪？

**入口：处理 → 清洗 →「API 端点」那一行右边的「流式输出」，默认关。**

它只决定「怎么收」响应，不改提示词，也不改清洗结果：

- **关（默认）**：等接口把整段 JSON 写完，再一次性解析。兼容性最好；接口不支持 SSE、或者中间网关爱把响应重新包一层时，走这条最稳。
- **开**：请求里带 `stream: true`，接口按 SSE 一段段往回推，插件一边收一边拼。长回复不用干等一整包 JSON；断流、返回网页、格式不对，也能更早报出来。

两件容易误会的事：

- **页面上不会逐字滚动。** 插件确实是边收边拼，但结果要等这一段收完才写进界面，不会像聊天那样一个字一个字往外蹦。想要「边出边看」的逐字效果，这个开关给不了。
- **中间隔着酒馆代理。** 请求经酒馆转发，代理一旦做了缓冲、压缩或改写，流式可能一直等到最后才整段到达，甚至报「流式响应中出现不合规的 JSON 数据」。遇到这种先关掉重试，再查地址和 Key。

> 它是全局开关：清洗、阶段概括、文风生成、角色 AI 人设等走「清洗 API」的请求都听它。清洗时如果全局提示词选「跟随酒馆预设」，请求交给酒馆预设那条链路，开关不起作用。

## 文风生成

**入口：处理 → 文风卡片。** 它不写剧情，只从这本书里取一段原文，让模型总结成一份「怎么写」的执行指南；之后每轮聊天把这份指南注入给 AI，让它模仿原著的叙述腔调、句式和用词，而不是照搬剧情。

| 控件 | 作用 |
|---|---|
| 生成文风 | 按当前设置取样本 → 调清洗 API → 结果写进「文风执行指南」 |
| 文风设置（齿轮） | 选采样来源（从原著采样 / 粘贴范文）、采样字数和段落 |
| 编辑提示词（`</>`） | 改生成指南用的提示词，改坏了点旁边的重置恢复默认 |

**从原著采样**（默认）：选「第 N 段」，再填采样字数（默认 1000，范围 200～5000），插件取该段开头这么多字发给模型。

- 段落下拉列的是**清洗后的分段**。提示「未找到对应段落原文」时，说明当前会话里没载入这段原文——先把小说上传、清洗好再采。
- 想避开序章、作者的话，换一段；想多覆盖几种写法，把字数调大，上限 5000。

**粘贴范文**：手头没有原文，或只想学某一种文风时，把 500 字以上有代表性的段落贴进「粘贴范文」，通常比短样本稳。

生成完成后：

- 结果在卡片下方，展开「文风执行指南」就能看和改。**可以直接改**，离开输入框时自动保存，下一轮注入的就是你改过的版本。
- 指南作为独立一块注入，默认 **主提示前 / 深度 4 / 系统角色**，可在 **处理 → 注入设置 → 文风** 里改。它没有单独的启用勾选：只要指南不为空、插件总开关开着就会发。
- 重新生成会**整段覆盖**旧指南。想留旧版本，先复制出去。

> 指南写的是「怎么叙述」，不是「接下来发生什么」。别把剧情大纲、人物设定塞进范文，否则模型会把它们当成写作要求一起模仿。

## 穿书与用户代入

在 **剧情** 页开启穿书模式，用正文状态栏或弹窗管理进度。

- 按归档进度确定当前节点，完成节点后继续推进；翻看预览不会改变实际注入节点。
- **自动推进**（默认开启）：每条 AI 回复结束后（可设成每 1–10 条判一次），用**当前对话模型**或**插件里配置的 API** 判断「当前节点演完没有」。模型只回一行 JSON，只有 `completed` 为真、且置信度达到阈值（默认 0.7）才前进到下一个未完成节点。判定提示词在 **剧情 → 自动推进 → 判定提示词**，改坏了点「重置默认」。
- **自动进入下一阶段**（默认开启）：本阶段所有节点都完成后，自动解锁并切到下一个「还有未完成节点」的阶段，光标落在它第一个未完成节点。关掉它就退化成「只在本阶段内推进，阶段走完停住」。
- 判定失败是**安全失败**：模型没回 JSON、置信度不够、请求超时，都**不推进也不弹错**，下一轮回复会再判一次——宁可晚一轮，不会跳节点。
- 状态栏「暂停」会一起挡住自动推进（暂停的本意就是先别往前走），恢复后从下一条回复继续判定。
- 自动推进只跟着**当前注入节点**：翻看预览、切换阶段、拖动分页都不会触发判定。
- 穿书模式的直接注入只发送**当前节点**；选择“压缩原文”时发送该节点所在的一个清洗分段。当前节点或正文不可用时会回退到阶段资料。
- 暂停会停用剧情直接注入及开场、推进、持续提示词；向量召回仍可运行，沉浸模式由自己的开关控制。
- 沉浸模式约束角色的信息边界；轻量化召回会裁掉明显晚于当前节点的内容，减少剧透。也可让 AI 推演后文建议。
- **穿书模式会从更早阶段召回前情，包括已关闭的历史阶段。** 关闭历史阶段不等于禁止它作为前情出现。
- 穿书进度按聊天独立保存。

在 **角色 → 用户代入** 中选择原著角色：

| 方式 | 效果 |
|---|---|
| 替换原角人生 | 原角色不再作为独立 NPC 注入，相关称呼按用户身份替换 |
| 扮演原角本人 | 将原角色资料作为用户的既有身份与人物基础 |

代入配置按聊天保存，称呼可以手动增删。替换发生在注入层，不改小说源数据与向量索引。

原著提供参考；如果聊天已改变人物命运或关系，可在剧情页做 **偏差分析**，把已发生的分支事实提供给 AI。偏差分析默认手动触发，也可开启按楼层自动更新。

删除聊天楼层或重新生成（regenerate）、编辑正文、换／删候选回复后，会自动清理来源失效的偏差事实和相关变更记录，同步调整楼层标记并回退受影响的总结进度，无需额外开启。判定靠每层的轻量签名（正文长度＋候选回复条数＋当前选项内容），所以「条数没变、只是原地改写」的重新生成也认得出。缺少来源楼层的旧手填事实会保留。

### 弹窗「留台单」：选阶段、选节点、推演、结算，都在一张小票上

**入口：剧情页打开穿书模式，显示方式勾「弹窗」，页面右下角就会出现「穿书存档」小按钮。** 按钮可以拖动，点一下开、再点一下关；点旁边的遮罩也能关。它把穿书进度做成一张餐厅小票——「留台单」就是留在台面上的点单存根。

| 小票上的字 | 对应什么 |
|---|---|
| 商品 / 阶段名 | 当前阶段；点这一行展开阶段清单 |
| NO. / 品类 / 节点 / 状态 | 当前阶段的节点表，品类分主线、支线、关键转折 |
| 小计 / 预付款 | 本阶段**已完成**的节点数 / **还没演**的节点数 |
| 条码 + 时间 | 最后一条 AI 回复的时间，纯装饰 |
| 谢谢惠顾 | 页脚装饰，没有点击功能 |

怎么用：

- **选阶段**：点「商品」展开阶段清单（分页，可改每页几个）。选一个阶段＝把进度挪到该阶段第一个节点，**不会顺手勾选或取消任何节点**。
- **选节点**：点节点行＝切到该节点，并把**同一阶段里排在它前面、还没勾的节点**一并标记为已完成。点行右侧的勾选框只改「这个节点算不算演过」，不动当前进度。当前节点那一行会展开概括、事件和伏笔，方便对剧情。
- **上下箭头**：只在当前阶段内**翻看**，不改进度——后台注入仍用你最后确认的那个节点。翻完记得点回要演的那一行。
- **✦ 推演**：现场跑一轮「下一步」推演，给三条候选（🌸 情感向 / ⚡ 张力向 / 🔮 伏笔向）。点任意一条，描述会直接填进聊天输入框，改不改由你。
- **暂停 / 恢复**：和状态栏上的暂停是同一个开关，会一起挡住自动推进；暂停时剧情直注与开场、推进提示词也停，向量召回照常。
- **副标题**：`阶段•节点标题 #楼层号`，楼层号取最后一条 AI 回复，方便对照聊天记录。

> 弹窗和状态栏是同一份进度，任一边改了节点，另一边立刻同步。箭头翻看不算改进度，别把「预览到哪」当成「演到哪」。

## 保存与备份

**设置 → 小说库** 可保存、加载、更新和重命名小说快照。长时间处理或编辑前，建议开启自动保存。

| 数据 | 存在哪里 |
|---|---|
| 设置、API 配置、小说库索引 | 酒馆设置 |
| 剧情角色、压缩正文、阶段数据 | 酒馆服务端文件，分别保存为 `*_core.json`、`*_chunks.json`、`*_stages.json` |
| 向量索引 | 当前浏览器的 IndexedDB |
| 穿书进度、用户代入配置 | 当前聊天的数据 |

**跨设备或换浏览器请用“导出 ZIP”备份。** ZIP 包含小说资料、阶段与向量，不包含 API 地址、Key 和模型名。仅复制酒馆设置，不能带走浏览器里的向量。

导入支持 ZIP 和旧版 JSON。导入会新增一本小说快照，**不会立即覆盖当前工作区**；手动加载新快照后才切换。旧版 JSON 不含向量。

### 清除缓存：两个按钮分别清什么

**入口：设置 → 清除缓存。**

- **清除向量缓存**：只清当前这本小说在浏览器 IndexedDB 里的向量索引，**不动**剧情、角色、阶段、压缩正文和设置；清完要重新向量化才能再召回。没加载小说时会直接提示「无缓存可清除」。
- **清除全部数据**：要**连点两次确认**——第一次问「确认清除全部数据？这将清空所有剧情、角色、阶段、向量缓存，且无法恢复！」，第二次再问「【再次确认】这会删除所有已清洗数据，确定吗？」。确认后清掉当前小说的向量、服务端三份重数据文件（`*_core.json`、`*_chunks.json`、`*_stages.json`）、剧情 / 角色 / 阶段 / 压缩正文 / 文风指南 / 偏差记录，并从小说库移除对应快照。**不能撤销**；设置、API 配置和主题不受影响。

> 只想重做检索就点第一个；第二个等于「这本不要了」。点之前先导出 ZIP，或确认小说库里还有能用的快照。

## 外观与主题

**入口：设置 → 外观配色。** 整张卡默认折叠，点标题展开。改的是插件自己的界面，不动酒馆主题，也不影响注入内容。

**主题下拉**自带三个预设：默认、星糖梦簿、星糖梦簿·夜间；自己新建或导入的主题排在后面。右边五个图标按钮依次是导入、导出、新建、删除、保存。

| 按钮 | 做什么 |
|---|---|
| 导入 | 选一个主题 JSON，存成自定义主题并立即套用 |
| 导出 | 把当前配色存成 `novel-injector-theme-<名字>.json`，方便备份或分享 |
| 新建 | 起个名字，把当前配色另存为一个新主题 |
| 删除 | 删自定义主题；删内置主题只是隐藏，插件自带的那套配色还在 |
| 保存 | 把当前颜色写进设置（见下） |

**六个颜色**：主色、次色、强调、警示在上，中间是 5 个开关，背景和文字在下。每行都有取色器和十六进制输入框，两边同步；输入不合法会标红，失焦后回到上一个有效值。

**5 个开关**：

- **跟随美化**（默认开）：背景色、文字色跟着酒馆底色走，下面两个取色器变灰。想自己指定底色就关掉它。
- **去除边框** / **去除卡片**：拿掉分割线和卡片外壳，适合嵌进酒馆原生面板、不想多一层「框中框」的时候。
- **状态栏跟随**：聊天结尾的阶段状态栏也用这套配色；关着时保持原样式。
- **图标替换**：用阿里 iconfont 换掉插件里的小图标；图标加载不出来就关掉。

**什么时候要点保存？** 改颜色、拨「去除边框 / 去除卡片」只是**即时预览**，不会马上写进设置，满意后点保存（软盘图标）。切主题、跟随美化、状态栏跟随、图标替换会**立即保存**，不用再点。刷新后回到最后一次保存的样子。

> 内置主题也能改：改完保存，会以「覆盖」的形式记在这个主题名下，之后每次选它都是改过的配色。想保留原样，改色前先「新建」一个自己的主题。

## 常见问题

**能不能增加“上下文注入位置”功能？**

已经有。**处理 → 注入设置 → 展开对应分类 → 注入位置 / 注入深度 / 消息角色。** 角色、阶段剧情、向量、世界设定等可以分开调。找不到时，先向下滚动并展开折叠项。

**清洗完了，为什么 AI 还是不知道小说内容？**

先检查插件总开关、阶段开关，以及对应的角色或世界设定是否开启。清洗只是生成资料，聊天时才注入；生成文风、世界设定等也需要操作各自模块。必要时查看酒馆实际发送的提示词，确认资料是否进入上下文。

**不做向量化能用吗？会不会一次把整本书塞进去？**

能用。普通模式只直接注入已开启的未向量阶段，并受 Token 上限约束；穿书模式通常只注入当前节点。想减少消耗，选“剧情节点”并只开启需要的阶段。

**清洗失败，该改哪里？**

| 提示 | 处理方法 |
|---|---|
| 429 / 请求过多 | 降低并发与每分钟请求数，稍后续跑；若提示额度不足，检查余额和配额 |
| 524 / 504 | 网关等待上游超时，稍后重试或减小分段；只提高插件超时通常无效 |
| 401 / 403 / 404 | 分别检查 Key、访问权限、接口地址与模型名 |
| JSON 语法或结构不合规、缺少 ni_meta | 模型没有按要求返回完整结果；重试，反复失败再检查清洗提示词或减小分段 |
| 输出被截断 / 缺少压缩正文 | 减小分段，检查模型输出上限与清洗提示词 |
| 请求超时 / 网络连接失败 | 检查接口、网络与酒馆服务；按需要调整超时或分段大小 |
| 模型拒绝 / 内容过滤 | 在“请求结构预览和失败响应记录”中查看实际返回；核对全局提示词及所选预设是否包含角色扮演、续写等与清洗冲突的要求 |

提示包含实际收到的接口信息。酒馆未提供原始状态码时会明确说明，不会把所有失败都归为同一种原因。只补失败段用 **续跑清洗**，无需整本重洗。

**改了阶段划分，要重新向量化吗？**

受影响阶段的索引会重置，需要重新向量化。更换向量模型后也应重建索引，避免新旧向量不兼容。向量失败可检查地址、Key、模型、限速及批量大小，并使用“诊断”查看缓存。

**AI 更新人设失败，或者某个角色被跳过？**

失败会显示原因，最多额外重试 3 次；截断时可换输出上限更高的模型。如果近期对话没有明确出现该角色姓名或可靠别名，会直接跳过，避免把别人的经历写进此人资料。

**代入角色没有可选称呼？代入会影响向量召回吗？**

称呼来自清洗提取的别名，旧数据可能没有，可手动添加或重洗相关段落。代入不会改向量索引，不影响检索。

**导入会覆盖当前小说吗？分享 ZIP 会带上 Key 吗？**

导入只新增快照，手动加载才切换。导出的 ZIP 不包含 API 地址、Key 和模型名。

**换浏览器后向量没了？**

向量存在浏览器本地。换浏览器或清空站点数据后，需要导入含向量的 ZIP，或重新向量化。

**MOBI 无法上传？**

支持无压缩与 PalmDoc 压缩的 MOBI。DRM 加密、Huff/CDIC 压缩及其他不支持的格式，请先转换为 TXT。

**顶部图标或穿书状态栏不见了？**

顶部图标在酒馆扩展菜单中开启，更新插件后先刷新页面。状态栏则检查剧情页的穿书开关与显示方式；显示异常可先折叠再展开，必要时刷新。

更多改动见 [更新记录](./更新记录.md)。排查日志可在浏览器控制台筛选 `[NI]` 或 `[NI-TB]`；提交问题时请附具体报错文字和操作步骤。
